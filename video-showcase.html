01用场景讲产品

三类用户，三条故事线

录视频时先讲“谁在用”，再切到真实功能。这样观众会更快理解 PoemGraph 的价值。

学生

明天要学一首诗。孩子打开年级入口，看拼音和注释，听一遍，做小练习，把“会背”变成“看得懂”。

家长

不想孩子一直盯屏幕。家长用听诗入眠、磨耳朵和彩色学习单，把诗词学习带到睡前、路上和纸上。

教师

一节课需要讲诗人、地点、时代和关系。老师用图谱、地图、时间轴和打印作业单组织课堂。

06录制镜头清单

建议 90 秒结构

每个 live demo 镜头保持 8-12 秒，页面之间用这份 showcase 串起来。录制时可以先讲场景，再切真实应用。

1开场：一句话介绍 PoemGraph，强调离线、课本对齐、三类用户。showcase
2学生：年级入口 → 诗详情 → 点注释 → 朗读 → 小测验。live
3探索：知识图谱双击展开 → 诗人朋友圈 → 点一条关系。live
4家长：听诗入眠 / 磨耳朵 → 打印彩色学习单或迁徙任务单。live
5教师：地图足迹 → 时间轴播放 → 历史大事旁白 → 教师作业单。live
6收尾：一个 HTML 文件，打开即用，适合学生、家长和老师。showcase
