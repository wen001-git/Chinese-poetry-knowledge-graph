重要提示：本工具只生成哈希（单向不可逆）。 SHA-256 设计上就不能从哈希反推回明文密码。 这是安全特性，不是 bug。 你发给用户的应该是明文用户名 + 密码，不是哈希。

使用流程：
1. 客户付款 19.9 元 → 加作者微信 leewen2017 收款
2. 打开本页面 → 「批量生成」标签 → 输入 用户名:密码（一行一个）
3. 点击「生成完整 accounts.json」→ 复制 JSON → 覆盖 poem.leewen.work 上的同名文件
4. 把「用户名 + 密码」发给客户（明文，不是哈希）
5. 客户登录失败？→「验证」标签 → 输入客户反馈的密码 + accounts.json 里的哈希 → 确认是否一致

工具特性：纯前端 SHA-256 · 离线可用 · 不上传任何数据 · 盐值必须与 poemgraph-pro.html 中的 pg-pro-salt-v1 一致
